# Учебный проект: система учёта обращений технической поддержки

Проект выполнен на Python с применением ООП. Для хранения данных используется SQLite, для интерфейса — Tkinter. Учебный прототип реализует рабочее место инженера технической поддержки.

## Возможности

- просмотр списка обращений;
- поиск по теме и описанию с корректной обработкой кириллицы;
- фильтрация по статусу;
- создание нового обращения;
- назначение обращения текущему инженеру;
- изменение статуса с проверкой допустимых переходов;
- просмотр и добавление комментариев;
- обработка ошибок ввода.

Правила переходов задаются по названиям статусов и не зависят от их числовых идентификаторов в базе данных.

## Запуск

```bash
python app.py
```

При первом запуске база `support_tickets.db` создаётся автоматически и заполняется демонстрационными данными.

## Тестирование

```bash
python -m unittest -v test_support.py
```

## Структура

- `models.py` — объектные модели;
- `database.py` — соединение и схема SQLite;
- `repository.py` — слой доступа к данным;
- `services.py` — бизнес-логика;
- `seed.py` — начальные данные;
- `app.py` — графический интерфейс;
- `test_support.py` — модульные тесты;
- `schema.sql` — SQL-схема базы данных;
- `docs/` — диаграммы IDEF0, Use Case и ERD.
