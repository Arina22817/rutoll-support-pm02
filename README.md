# Система учёта обращений технической поддержки ООО «Рутолл»

Учебный проект по ПМ.02 «Осуществление интеграции программных модулей».

Приложение моделирует рабочее место инженера службы технической поддержки и оформлено по принципу service desk / issue tracker.

## Возможности

- очередь обращений с поиском и фильтрацией;
- полноценная карточка обращения с ключом `RS-...`;
- поля ПВП, полоса, тэг, компонент, автор, исполнитель;
- тип, приоритет, категория, окружение, версии, решение;
- несколько инженеров технической поддержки;
- назначение обращения выбранному инженеру;
- изменение статуса с проверкой допустимых переходов;
- комментарии непосредственно в карточке заявки;
- хранение данных в SQLite;
- объектно-ориентированная архитектура;
- автоматические тесты `unittest`.

## Основные файлы

- `app.py` — главное окно и карточка заявки;
- `database.py` — подключение, структура и миграции SQLite;
- `models.py` — модели предметной области;
- `repository.py` — слой доступа к данным;
- `services.py` — бизнес-логика;
- `seed.py` — справочники и демонстрационные данные;
- `schema.sql` — SQL-схема;
- `test_support.py` — тесты;
- `support_tickets.db` — готовая демонстрационная база;
- `docs/` — диаграммы и скриншоты.

## Запуск

```bash
python app.py
```

Дополнительные библиотеки не требуются.

## Тесты

```bash
python -m unittest -v test_support.py
```

## Проверка

Финальная версия проходит 10 из 10 автоматических тестов. `PRAGMA integrity_check` возвращает `ok`, нарушений внешних ключей не обнаружено.


### Удаление заявки
Заявку можно удалить из главного окна или из карточки. Перед удалением приложение запрашивает подтверждение. Связанные комментарии удаляются автоматически.
